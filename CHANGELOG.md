# Changelog

## 1.3.1

- Сохранён независимый таймер восстановления кнопки после ухода на другой сайт, включая возврат с пропущенным событием `pageshow`.
- Ошибки API Tampermonkey при восстановлении страницы больше не останавливают кнопку и не прерывают завершение перетаскивания.
- Критичные стили и координаты восстанавливаются независимо от узла стилей, добавленного менеджером скриптов.
- Чтение настроек и повторная регистрация меню отложены до завершения обработки событий жизненного цикла страницы.
- Перетаскивание, сохранённое положение и обычный переход по ссылке сохранены.
