# Кинопоиск → Kinokino

Скрипт для Tampermonkey: добавляет небольшую серую кнопку **«Смотреть бесплатно»** на страницах фильмов и сериалов Кинопоиска. Изначально она находится слева, по центру высоты экрана. Кнопку можно зажать и перетащить мышью или пальцем; выбранное положение сохраняется между страницами и запусками браузера. Кнопка остаётся видимой при прокрутке. Обычное нажатие открывает в той же вкладке адрес на `kinokino.vip`, сохраняя путь, ID, параметры и якорь.

```text
https://www.kinopoisk.ru/series/160958/
                         ↓
https://kinokino.vip/series/160958/
```

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) для своего браузера.
2. Откройте меню Tampermonkey → **«Создать новый скрипт»**.
3. Удалите шаблон, вставьте всё содержимое файла [`kinopoisk-kinokino.user.js`](./kinopoisk-kinokino.user.js) и сохраните (`Ctrl+S`).
4. Обновите страницу фильма или сериала на Кинопоиске. Слева по центру появится серая кнопка **«Смотреть бесплатно»**.

В Chrome, если Tampermonkey сообщает, что выполнение пользовательских скриптов отключено, следуйте [его инструкции по разрешению userscripts](https://www.tampermonkey.net/faq.php#Q209).

### Положение кнопки

- Зажмите кнопку основной кнопкой мыши или пальцем и перетащите в удобное место.
- После отпускания положение сохранится в хранилище Tampermonkey для этого скрипта. Оно общее для страниц фильмов и сериалов, включая адреса с `www` и без него.
- Небольшое движение до 6 px считается обычным нажатием. После перетаскивания переход по ссылке не выполняется.
- При изменении размера окна положение адаптируется так, чтобы кнопка оставалась в пределах экрана. Отмена жеста возвращает прежнее положение.
- Для возврата к исходному месту откройте меню Tampermonkey → **«Сбросить положение кнопки»**.

### Обновление до 1.3.1 и отсутствие кнопки

Замените **весь** код уже установленного скрипта актуальным содержимым `.user.js`, сохраните и перезагрузите вкладку Кинопоиска. Не создавайте вторую копию. Версия 1.3.1 сохраняет нейтральный элемент внутри `body` и Shadow DOM для защиты от типичных косметических фильтров блокировщиков. Скрипт восстанавливает удалённую кнопку, атрибут `hidden` и изменённые свойства видимости. Отключать Adblock не требуется. Произвольный пользовательский фильтр, специально нацеленный на эту кнопку, может потребовать точечного исключения.

После перезагрузки в меню Tampermonkey на вкладке должен появиться пункт **«Показать кнопку Kinokino (1.3.1)»**. Его наличие подтверждает запуск скрипта; нажатием можно восстановить кнопку. Если пункта нет, проверьте разрешение Chrome **«Разрешить пользовательские скрипты»** в настройках расширения Tampermonkey и доступ расширения к `www.kinopoisk.ru`. Включение скрипта в панели Tampermonkey само по себе не подтверждает разрешение браузера на его запуск. Подробнее — [официальная инструкция Tampermonkey](https://www.tampermonkey.net/faq.php?ext=fire&q=Q209).

### Возврат с сайта просмотра

Страховочный таймер DOM-восстановления сохраняется при уходе со страницы; при заморозке браузер сам приостанавливает его выполнение. Возврат не зависит только от события `pageshow`. Обращения к хранилищу, стилям и меню Tampermonkey выполняются отдельно: временно недоступное API не мешает показать кнопку, открыть ссылку или завершить перетаскивание. Основное оформление и координаты восстанавливаются через CSSOM даже после потери добавленного менеджером узла `<style>`.

Перед стабильным релизом следует проверить именно установленный Tampermonkey: открыть Kinokino кнопкой, вернуться браузерным «Назад» несколько раз и убедиться, что кнопка появляется без F5 и сохраняет положение. Стенд с эмуляцией API не заменяет этот сценарий.

## Как работает

- Поддерживает `kinopoisk.ru` и `www.kinopoisk.ru`, пути `/film/ID` и `/series/ID`, включая вложенные разделы.
- На главной, в поиске и на страницах персон кнопка не показывается.
- Обновляет ссылку при переходах внутри сайта без перезагрузки, при возврате назад и вперёд. Восстановление страницы из кеша браузера и повторный запуск поверх сохранённой кнопки заново подключают обработчики без дубликатов таймеров.
- Положение задаётся относительно доступного пространства окна, с отступом от края 16 px на широком экране и 12 px на узком. Кнопка не занимает полосу над шапкой и остаётся видимой при прокрутке.
- Изолирует оформление кнопки через Shadow DOM, поэтому не зависит от CSS-классов Кинопоиска.
- Использует API Tampermonkey для оформления, меню и сохранения положения; не использует внешние библиотеки и не делает фоновых сетевых запросов. Координаты сохраняются только в хранилище скрипта; переход происходит только по нажатию.

Скрипт меняет ссылку. Доступность стороннего сайта и видео зависит от самого `kinokino.vip`.

## Проверка

Для разработки используются Node.js `24.21.0`, npm `11.19.0` и Biome (версия закреплена в lockfile). Самому скрипту эти инструменты не нужны.

```sh
cd /path/to/kinopoisk-extension
npm ci --ignore-scripts
npm run hooks:install
npm run verify
```

`verify` проверяет синтаксис, форматирование, lint и поведение в DOM-стенде Node.js. Отслеживаемый `.githooks/pre-push` и GitHub Actions запускают ту же проверку. На новом checkout установите hook командой выше. Отдельных этапов TypeScript и сборки нет: устанавливается сам JavaScript-файл. Настройки окружения и секреты не требуются.

Для `.user.js` адресно отключена проверка `noRedundantUseStrict`: Tampermonkey исполняет файл как обычный скрипт, а Biome по расширению `.js` предполагает модуль. Остальные рекомендованные правила включены; предупреждения lint блокируют проверку.

Проверка в Node.js не заменяет запуск в Tampermonkey. При приёмке в браузере проверьте страницу сериала и фильма, переход между ними, возврат назад, отсутствие кнопки в поиске, а также положение и доступность кнопки на широком и узком экране. Доступность видео на стороннем сайте проверяется отдельно.
