# Кинопоиск → Kinokino

Скрипт для Tampermonkey: добавляет слева кнопку **«Смотреть бесплатно»** на страницах фильмов и сериалов Кинопоиска. По нажатию открывает в той же вкладке адрес на `kinokino.vip`, сохраняя путь, ID, параметры и якорь.

```text
https://www.kinopoisk.ru/series/160958/
                         ↓
https://kinokino.vip/series/160958/
```

## Установка

1. Установите [Tampermonkey](https://www.tampermonkey.net/) для своего браузера.
2. Откройте меню Tampermonkey → **«Создать новый скрипт»**.
3. Удалите шаблон, вставьте всё содержимое файла [`kinopoisk-kinokino.user.js`](./kinopoisk-kinokino.user.js) и сохраните (`Ctrl+S`).
4. Обновите страницу фильма или сериала на Кинопоиске. Слева появится оранжевая кнопка **«Смотреть бесплатно»**.

В Chrome, если Tampermonkey сообщает, что выполнение пользовательских скриптов отключено, следуйте [его инструкции по разрешению userscripts](https://www.tampermonkey.net/faq.php#Q209).

## Как работает

- Поддерживает `kinopoisk.ru` и `www.kinopoisk.ru`, пути `/film/ID` и `/series/ID`, включая вложенные разделы.
- На главной, в поиске и на страницах персон кнопка не показывается.
- Обновляет ссылку при переходах внутри сайта без перезагрузки, при возврате назад и вперёд.
- На узком экране кнопка располагается слева внизу.
- Изолирует оформление кнопки через Shadow DOM, поэтому не зависит от CSS-классов Кинопоиска.
- Не запрашивает дополнительных разрешений Tampermonkey, не использует внешние библиотеки и не делает фоновых сетевых запросов. Переход происходит только по нажатию.

Скрипт меняет ссылку. Доступность стороннего сайта и видео зависит от самого `kinokino.vip`.

## Проверка

Для разработки используются Node.js `24.21.0`, npm `11.19.0` и Biome (версия закреплена в lockfile). Самому скрипту эти инструменты не нужны.

```sh
cd /path/to/kinopoisk-extension
npm ci --ignore-scripts
npm run hooks:install
npm run verify
```

`verify` проверяет синтаксис, форматирование, lint и поведение в DOM-стенде Node.js. Отслеживаемый `.githooks/pre-push` и GitHub Actions запускают ту же проверку. На новом checkout установите hook командой выше. Отдельных этапов TypeScript и сборки нет: устанавливается сам JavaScript-файл. Настройки окружения и секреты не требуются.

Для `.user.js` адресно отключена проверка `noRedundantUseStrict`: Tampermonkey исполняет файл как обычный скрипт, а Biome по расширению `.js` предполагает модуль. Остальные рекомендованные правила включены; предупреждения lint блокируют проверку.

Проверка в Node.js не заменяет запуск в Tampermonkey. При приёмке в браузере проверьте страницу сериала и фильма, переход между ними, возврат назад, отсутствие кнопки в поиске, а также положение и доступность кнопки на широком и узком экране. Доступность видео на стороннем сайте проверяется отдельно.
